# Task 7 - Test Natural-Language Telemetry Queries

## Objective

The objective of Task 7 is to test the natural-language grid assistant using different telemetry-related queries and verify that the system provides meaningful responses.

## Description

The natural-language telemetry interface allows users to enter questions using normal language.

The system processes the user's query and provides information related to power consumption, forecasting, voltage, frequency, and grid status.

This task focuses on testing the natural-language query functionality developed in the previous task.

## Technologies Used

- Python
- Streamlit
- Pandas
